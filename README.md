# Curso Lógica – Exercícios de Programação em Portugol

Este repositório contém os exercícios de lógica apresentados na **Aula 3** do curso *Lógica de Programação* (Senac). Cada arquivo tem a extensão `.por` e foi escrito em **Portugol**, uma linguagem pedagógica em português que facilita o aprendizado de algoritmos.

## 📚 Exercícios incluídos

| Arquivo | Descrição |
|--------|-----------|
| `Area.por` | Calcula a área de um triângulo a partir da base e altura informadas pelo usuário. |
| `IMC.por` | Calcula o Índice de Massa Corporal (IMC) e indica a classificação (baixo peso, peso normal, etc.). |
| `Maior de idade.por` | Verifica se a pessoa tem idade suficiente para ser considerada maior de idade. |
| `Maior entre 2 num.por` | Determina o maior valor entre dois números digitados. |
| `Media.por` | Calcula a média aritmética de quatro notas e informa se o aluno foi aprovado. |
| `Positivo ou Negativo.por` | Informa se um número informado é positivo ou negativo. |
| `Temperatura.por` | Converte temperatura de Celsius para Fahrenheit e vice‑versa. |

## 🚀 Como usar

1. **Instale um interpretador de Portugol** (por exemplo, o *Visualg* ou o *Portugol Studio*).
2. Abra o arquivo `.por` desejado.
3. Execute o programa e siga as instruções na tela.

## 🎨 Apresentação web

Uma página web interativa foi adicionada ao repositório (`index.html`). Ela exibe cada exercício com destaque visual, permitindo que você copie o código facilmente durante a apresentação.
